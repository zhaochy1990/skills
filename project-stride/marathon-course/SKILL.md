# 马拉松官网与赛道查询

输入：一个马拉松比赛的名字（可能是简称、俗称，也可能带年份）。
输出四样东西：

1. **官网**：赛事官方网站的 URL。可能没有——没有就明说"未找到官网"，并附上实际的信息发布渠道（公众号/报名平台等）。
2. **文字赛道**：按组别（全程/半程/欢乐跑…）**各输出一条**，每条是按跑进顺序排列的道路序列，格式 `道路A（起点）→道路B→…→道路Z（终点）`，折返点标注（折返）。
3. **起跑时间**：鸣枪时间，带日期。有的赛事分组别分枪起跑（全马 7:30、半马 7:50 之类），分枪的按组别各写各的。
4. **赛事规模**：**分组别名额**（全马 X 人 / 半马 Y 人 / …），能拿到总数也一并写。很多赛事只公布总数不公布分项名额——查不到分项就只写总数并注明，别按组别瞎拆。注意口径：官方公布的规模（名额）≠ 报名人数 ≠ 实际参赛人数，新闻里三种都会混着写，优先取官方口径并注明来源。

赛道逐年会改，起跑时间和规模也是逐届变的——输出必须注明对应的是哪一届（年份）。组别之间路线、终点、名额往往不同（全马、半马终点不同是常态），必须分开整理，不能只给全程一条顶全部。

## 第 1 步：锚定比赛

- 补全赛事全称和举办城市。简称可能有歧义（"西马"通常指西安，但要看上下文），理解有偏差时在结果里说明你按哪个比赛查的。
- 用户没说年份就停下请求用户确认年份
- 列出该届设置的组别（全马/半马/欢乐跑/健康跑…）及各组别起终点——竞赛规程和赛事新闻里都有。用户点名只要某个组别时可以只出那个，但要说明只查了这一组。
- 国际赛事用英文名搜（如 `Chicago Marathon course`）；国内赛事用中文名搜。

## 第 2 步：找官网

1. 搜索 `{比赛名} 官网`；国内赛事加搜 `{城市} marathon`。
2. **候选 URL 必须验证后才算官网**（本项目的赛事库里有域名过期后被抢注成赌博站的先例）：
   - 打开候选站点，确认页面内容命中该赛事（赛事名、主办单位），不是空壳/跳转/山寨站；
   - 官网常见形态是托管在赛事运营平台的独立域名（如西马的 xi-ma.com 托管在汇跑 platform 上）——域名与赛事对应即可，不必纠结由谁建站；
   - 报名中介（最酷、跑跑网、马拉马拉、数字心动等）和媒体专题页**不算官网**，算第三方平台。
3. 工具提示：WebFetch 对不少国内站点会报 TLS 证书错误（自签名、域名不匹配），失败时改用 `web_reader` MCP 工具抓取，它能读 http 和证书异常的站点。搜索引擎给的链接有时被截断得只剩域名，用 `site:` 限定或换关键词重搜可以找回完整文章 URL。
4. 很多国内赛事没有独立官网，只在官方微信公众号或报名平台发布信息。这算"未找到官网"，但把实际渠道告诉用户。

## 第 3 步：找赛道、起跑时间与规模

赛道来源按可信度从高到低尝试，拿到完整路线即停：

1. 官网/官方公众号的"赛事介绍""路线"页面。
2. **交管通告**：搜 `{比赛名} 交通管制`、`{城市} 马拉松 交通管制措施 通告`。交警封路通告按时间顺序逐条列出赛道经过的道路，通常是最完整的文字赛道来源；通告开头一般也写明比赛日期、鸣枪时间和总参赛人数——起跑时间和总规模顺手就能拿到。
3. 跑步媒体与报名平台的路线文章：搜 `{比赛名} 竞赛规程`、`{比赛名} 比赛路线`、`{比赛名} 半程马拉松路线`。官网正文抓不到时（JS 单页应用常见，如杭马的 hzim.org），竞赛规程的媒体转载（本地宝、跑步媒体）往往整段照登路线，是捷径。规程里各组别是分节列的（"（一）马拉松路线 /（二）半程马拉松路线"），按节各提各的。

起跑时间与规模的补充来源：

- **竞赛规程**："比赛时间和地点"给鸣枪时间；"比赛项目及规模"或"报名办法"给分项名额（全马/半马/欢乐跑各多少人的表格）。
- **赛事新闻**：报名启动、抽签结果、通气会报道常报总规模和分项名额，搜 `{比赛名} 规模 名额 全马 半马`、`{比赛名} 鸣枪 起跑时间`。
- 分枪起跑的赛事，各枪时间在规程"比赛办法"或官方公众号的检录须知里。

提取规则：

- 按跑进顺序记录道路名，**去掉紧邻的重复，但折返后再次经过的同一路段必须保留**：
  `→灞河东路→上善巷（折返）→上善巷→灞河东路→` 是正确的，不要去重成只出现一次。
- 起点、终点、折返、下穿/上跨等关键节点缀在道路名后：（起点）（终点）（折返）（下穿隧道）。通告里的"（逆行）"这类运行细节可保留为后缀，也可省略；但省略标注不等于省略该路段。
- 折返点若本身是 Named 地点（如"上善巷折返处"），写 `上善巷折返处（折返）`；若只是某路口，写 `XX路与YY路路口折返处（折返）`。
- **分组别提取，各组别的道路不要互相混**：半马常与全程前半段共线、中途分岔——能确认分岔点就在路线里注明"与全程共线至 XX 后分岔"，不能确认就逐段照实列。
- 某个组别的逐段路线查不到，就对该组别写"未查到"，**不要拿全程路线顶替**，也不要只写个终点交差。
- 只找到旧年份路线时如实说明年份。

## 第 4 步：自检

- 检查道路序列在地理上是否连贯：相邻道路应能相接，城市内的路线不应无故跨城跳断。明显跳断 = 提取漏了路段，回去补查。
- 距离粗验：全程约 42 公里、半程约 21 公里、欢乐跑约 5 公里。某组别提取出的路段串明显撑不到这个距离（比如只有 3、4 段），大概率漏了或拿到的只是部分路线。各组别终点要与官方公布一致——全马、半马终点不同是常态，半马终点却写成全马终点就是串组了。
- 规模粗验：各分项名额之和应与官方总数大体相符（差得远说明其中一个是别的年份或别的口径）。抽签赛事的"报名人数"远大于名额，别把报名人数当规模写。
- 查不到、无法核实的部分如实说明。**不要编造路名、URL 或数字**——宁可输出"XX 未能查到"，也不要补一条看起来合理的。

## 赛道难点：交给 course-challenges skill

本 skill 只负责官网、路线串、起跑时间、规模。用户接着要赛道**难点**——总爬升、坡道（桥/引桥/隧道）、折返、侧风段、**拥堵堵点（跑友口碑检查）**——时，使用 `course-challenges` skill 处理；它的结论以本 skill 产出的届份正确的路线串为锚，两个 skill 配套使用。

## 输出格式

```text
官网：https://www.xi-ma.com
（或：未找到官网；信息发布渠道：官方微信公众号"西安马拉松"）

比赛（2025 XX马拉松）：

起跑时间：2025-11-02（周日）07:30（全程、半程同枪；分枪则按组别各列）
规模：全程 20000 人 / 半程 15000 人 / 欢乐跑 5000 人；总 40000 人
（分项名额查不到时：规模：总 40000 人（官方仅公布总数，分项名额未查到））

赛道：

【全程】
A路（起点）→B路→…→奥体中心体育场（终点）

【半程】
A路（起点）→…（与全程共线至C路口后分岔）→…→市民广场（终点）

【欢乐跑】
A路（起点）→…→平湖秋月（终点）

（某组别查不到逐段路线时：【半程】未查到逐段路线，仅确认终点为 XX）
```

## 示例

输入：`西安马拉松`

输出：

```text
官网：https://www.xi-ma.com

比赛（2024 西安马拉松；据西安交警交通管制通告）：

起跑时间：2024-11-03（周日）07:30
规模：总 3.5 万余人（交警通告口径，设全程/半程/欢乐跑；分项名额未查到）

赛道：

【全程】
永宁门东侧盘道（起点）→南大街→钟楼盘道→东大街→长乐门盘道→环城东路北段→太华南路→太华北路→永顺路→御井路（逆行）→永隆路→浐灞三路→广运潭大道→欧亚大道→灞河东路→东三环北侧辅路→会展一路→欧亚大道→灞河东路→上善巷→上善巷折返处（折返）→上善巷→灞河东路（逆行）→灞河东路与河堤路南侧折返处（折返）→灞河东路（逆行）→西安奥体中心西广场南侧道路→西安奥体中心体育场（终点）
```

2024 西马另设半程、欢乐跑组别，各有自己的路线——输出时按【半程】【欢乐跑】各列一节；逐段路线查不到就写"未查到"，不用全程顶替。

同一比赛的赛道逐年会变：网上流传的旧版本可能与最新通告不一致（例如带"朝阳门下穿隧道""永顺东路"的串是早几年的走法）。遇到不一致，以能查到的最新官方通告为准，并如实标注年份。
